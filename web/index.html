      Under the hood

      Look, decide, act, check

      LeanWatch runs the same loop a robot arm does. It looks at the screen, decides on the next move, moves the cursor, then checks whether the move worked before taking the next one.

      Safety rules the agent follows

      • Nothing moves until you grant permission, and permission ends when you close the session.
      • Esc or the Stop button halts it immediately. On a real computer, slamming the mouse into a screen corner also stops it.
      • If you move the mouse yourself, the agent pauses and lets you take over.
      • Deleting, sending, buying and installing always need your click on Allow.
      • Text written on web pages or in documents is never treated as an instruction.
      • The local agent only listens on 127.0.0.1 and needs a secret session token.

      Run it on your computer

      1. Install Python 3.10 or newer.
      2. In a terminal: cd agent then pip install -r requirements.txt
      3. Sign in to the Claude API: set ANTHROPIC_API_KEY or run ant auth login.
      4. Start it: python -m leanwatch. Your browser opens this page, already connected.
      5. Optional: python -m leanwatch --overlay adds the floating command box to the bottom-right corner of every screen.
      6. Try it safely first with --dry-run: the agent plans and narrates but never moves the mouse.
